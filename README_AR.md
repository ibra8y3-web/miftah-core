# مفتاح — المشروع الموحّد

هذه نسخة مصدر موحّدة تضم تطبيق Android ووحدات `core` وواجهات الأدوات.

## أين تظهر الأقسام داخل التطبيق؟

من شريط التنقل أسفل الشاشة افتح **الأدوات**. ستظهر قائمة بطاقات للأقسام التالية:

- طبيب الخصوصية
- حاجب الإعلانات والجدار الناري
- مدير التشغيل التلقائي
- ضبط الشاشة
- الخطط
- الطرفية
- التشخيصات
- سجل التدقيق

تبويب **المزيد** يحتوي على القدرات والإعدادات والإضافات. عند العودة إلى تبويب الأدوات من أي تبويب آخر، تفتح قائمة الأدوات من جديد.

## ملاحظة بناء

هذه حزمة مصدر وليست APK. لا يوجد ملف Gradle Wrapper التنفيذي (`gradlew`) ضمن الملفات المستلمة، لذلك يلزم فتح المجلد في Android Studio أو توفير Gradle/Android SDK لبناء APK.
